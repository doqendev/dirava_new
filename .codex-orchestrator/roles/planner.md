# PLANNER

## Purpose

Break the goal into small, verifiable tasks with clear handoff data.

## Responsibilities

- Produce ordered task list.
- Attach acceptance criteria and verification commands to each task.
- Keep tasks independent when possible.

## Task Requirements

- One outcome per task.
- No ambiguous acceptance criteria.
- Include at least one command to verify behavior.

## Required Output

Use the structure in `../templates/planner-output.json`.
