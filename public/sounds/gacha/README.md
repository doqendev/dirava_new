# Gacha Sound Effects

This directory should contain the following sound files for the mystery box reveal animation:

## Required Files

| File | Description | Duration |
|------|-------------|----------|
| `box-shake.mp3` | Anticipation building sound during box shake phase | ~2 seconds, loopable |
| `box-open.mp3` | Burst/explosion sound when box opens | ~0.5 seconds |
| `reveal-common.mp3` | Simple chime for common items | ~1 second |
| `reveal-rare.mp3` | Mystical tone for rare items | ~1.5 seconds |
| `reveal-epic.mp3` | Powerful reveal sound for epic items | ~2 seconds |
| `reveal-legendary.mp3` | Epic fanfare for legendary items | ~3 seconds |

## Recommendations

- Use royalty-free sound effects
- Keep file sizes small for web performance (ideally under 100KB each)
- MP3 format is preferred for broad browser support
- Consider using services like:
  - [Freesound.org](https://freesound.org)
  - [Mixkit](https://mixkit.co)
  - [Zapsplat](https://www.zapsplat.com)

## Sound Design Guidelines

- **box-shake**: Building tension, rattling or shaking sounds
- **box-open**: Satisfying "pop" or burst, like unwrapping
- **reveal-common**: Light, pleasant chime - understated
- **reveal-rare**: More magical, with some sparkle
- **reveal-epic**: Dramatic reveal with impact
- **reveal-legendary**: Full fanfare, victory music, excitement
